## C-09 · גרסת הנכסים לא הועלתה — הדפדפן הגיש CSS ישן ✅ תוקן

**איך התגלה.** בבדיקה ויזואלית של /media במובייל נמדדו **18 מתוך 48 ציטוטים חתוכים**. נראה
כפגם אמיתי — עד שהתברר שהסגנון המחושב מדווח `-webkit-line-clamp: 6`, בעוד המקור אומר `8`.
**6 הוא הערך שלפני התיקון** — כלומר הדפדפן הגיש גיליון סגנונות מהמטמון.

**האימות.** משיכת ה-CSS מהשרת הראתה שהוא **זהה בייט-בבייט** לקובץ המקומי — הפריסה כן נחתה.
הזרקת ה-CSS האמיתי לדף חיה הורידה את החיתוך **מ-18 ל-0**.

**הפגם האמיתי.** `wp_enqueue_style` מקבל את הגרסה מ-`wp_get_theme()->get('Version')`, כלומר
מכותרת `style.css`. היא נותרה `1.5.7` לאורך כל השינויים של S006, ולכן **כתובת ה-CSS לא השתנתה
ודפדפנים המשיכו להגיש את הגרסה הישנה**. אייל, שכבר ביקר באתר, היה רואה ציטוטים קטועים ומייחס
זאת לנו.

**התיקון (בוצע).** `style.css` → `Version: 1.5.8`. נפרס ואומת: הדף מבקש כעת
`chapters.css?ver=1.5.8`, ובשני המסכים **0 ציטוטים חתוכים**.

**מסקנה לאבן הדרך — נכנסת לאמנה.** כל פריסה שכוללת שינוי CSS או JS **חייבת** להעלות את
`Version` ב-`style.css`. בלי זה הבדיקות שלנו עוברות (אנחנו מושכים עם cache-bust) בעוד
שהסוקר האנושי רואה את הגרסה הישנה — כשל שקט שנראה כמו באג שלנו.
