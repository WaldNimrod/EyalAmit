## Two things that will bite whoever touches this next

**`hub/dist/` is gitignored.** The copy on the server and the copy in `hub/dist/` are build
output. The tracked source is the one under `_COMMUNICATION/`; edit that, copy it over, publish.

**The hub index edit is NOT tracked and NOT generated by the builder in a way that knows about
this form.** If `scripts/build_eyal_client_hub.py` regenerates `hub/dist/index.html`, the three
links to this form disappear from the hub home page while the form itself stays reachable at its
URL. After any hub rebuild, re-add them — top nav, lead card, secondary row — or fold the form
into the builder properly.

**Do not publish the hub from a git worktree.** The default prune deletes remote files absent
locally, and the ~1,000 media files under `hub/dist/files/` are gitignored and therefore missing
in a worktree. Publish from the main checkout, or pass `--no-prune`.
