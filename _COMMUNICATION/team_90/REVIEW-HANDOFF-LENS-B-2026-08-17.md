## Findings

1. **blocker — `ברור` → execute has no classification lock.** «Text is wrong + a folder exists» becomes new sentences on the live page; the validator is told to assert them and returns PASS. **Fix:** `ברור` only with quoted source cell/line **and** exact replacement bytes; otherwise `לא ברור`. Builder gets only those bytes. Validator fails any new string not in the cited source.
2. **blocker — first-action gate is a courtesy.** CURRENT ב.2 + same-turn start, or «יאללה» on a six-page form. **Fix:** required reply `סקואופ אושר: <rows> בלבד`; ban same-turn execution; CURRENT’s «next» is not approval; one page unless Nimrod writes more.
3. **blocker — write channel / ACF ban / file map absent.** Page 3 or 20 has no defaults file; builder writes to a template, mu-plugin, or wp-admin. Eyal-approved copy dies on reseed or diverges. **Fix:** copy charter §5 into the cycle; missing defaults file → escalate, do not invent a path.
4. **blocker — no anti-invention validator; empty ≠ FAIL.** Invented copy is certified. **Fix:** mandatory source-match / unmapped-hunk / provenance / empty=FAIL; name the wrapper; team_100 still reads only the verdict.
5. **major — two iron rules collide** on uncommented empty/heading-only blocks. Eyal sees missing sections he never asked to remove, or blank cards again. **Fix:** empty-card wins only when there is no renderable body; a remaining name/heading still needs a tracker item and Nimrod.
6. **major — «היעדר הערה = אישור» contradicts א.4 and the charter on מצוי≠רצוי.** Desired order never sticks, or is applied and later reverted. **Fix:** delete the standalone bold sentence; keep only «מצוי=רצוי ∧ אין הערה → מחוץ להיקף».
7. **major — Version bump and explicit-path commit demoted to validator traps.** C-09 repeats; `git add -A` ships a foreign file. **Fix:** put both back on cycle steps 5 and 7 as CURRENT has them.
8. **major — shared partials, permalinks/QR, media unnamed.** `/lessons/` rewrites homepage items waiting for Eyal; a QR slug cleanup is permanent; a session picks or generates a photo. **Fix:** shared files out of page scope unless Nimrod adds them; permalinks frozen; unnamed media = `לא ברור`.
9. **major — ingest = work list with no citation rule.** Nimrod’s shorthand becomes client-facing copy. **Fix:** ingest lists which rows changed; it does not authorise new words without a file/cell or a pasted replacement.
10. **major — source `אין` has no procedure.** `/learning/` and most of stage 2 will diverge by session. **Fix:** default = do not open the page; only Nimrod authorises an empty-card sweep.
11. **major — Grok listed on both builder and validator sides.** Iron Rule #1 becomes paper. **Fix:** align א.7 with charter §8א; forbid the builder’s exact model id from the validator slot.
12. **minor — no dirty-tree, FAIL-verdict, page-exit, Eyal-send, staging-host, or rollback lines.** Competent improvisation still damages staging. **Fix:** five must-lines in א.4/א.8.
